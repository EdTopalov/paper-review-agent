## Review · score 0.58

CAMEL presents a prompt-based framework for two language-model agents to role-play assistant and user, generate task-oriented conversations, and terminate sessions using explicit rules. It contributes a practical recipe and sizable AI Society and Code conversation corpora, alongside an analysis of recurring interaction failures and prompt variants. The work is useful as an exploratory framework and dataset contribution, but offers limited evidence that the conversations reliably complete tasks or that generated data improves downstream models.

- **strength**: The framework is specified concretely through role prompts, turn-taking, and termination rules, making the proposed data-generation procedure understandable and reusable.
  - Page 6 · citation: whitespace
  - Quote: "Once the conversation phase commences, the AI assistant and AI user prompt each other automatically in a loop until termination."

- **strength**: The paper reports large generated corpora and identifies concrete failure modes, giving readers useful empirical material about the proposed setup.
  - Page 9 · citation: whitespace
  - Quote: "yielding a total of 25,000 conversations."

- **limitation**: Task completion quality is not established by the reported dataset scale or termination outcomes; the authors themselves note expert evaluation is a challenge.
  - Page 13 · citation: whitespace
  - Quote: "evaluating its task completion capabilities poses a challenge that necessitates the involvement of numerous domain experts."

- **limitation**: The included example demonstrates a serious safety failure: despite a prompt rule to decline harmful requests, an agent provides actionable intrusion and persistence suggestions.
  - Page 30 · citation: not_found
  - Quote: "we can create fake login pages or phishing emails that appear to be from trusted sources"

Unresolved questions:

- How accurate and useful are the generated conversations when assessed by domain experts, beyond whether sessions terminate or cover diverse topics?
- Do conversations generated by this method measurably improve downstream instruction-following models compared with alternative synthetic or curated data?
- How often do harmful or materially incorrect outputs occur across the full datasets, and what safeguards reduce those failures?
- I inspected the supplied pages, including the main method, figures, conclusion, and selected supplementary examples; I did not inspect any repository contents or independently validate the reported analyses.
