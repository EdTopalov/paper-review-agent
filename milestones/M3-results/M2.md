# Original 20-paper review results

[Machine-readable results, per-paper statistics, and raw trace links](m2-results.json)

Each model block uses only complete repetitions shared by all four methods. Every included repetition has the unchanged 20 papers. Failed attempts remain in completion, token, cost, and latency denominators. Verified success means a completed review whose citations all pass the source checker; it does not measure assessment quality.

Steps are controller decisions; calls are API requests including retries. Tokens, USD and seconds are means per attempted paper, including failures. Unknown costs stay unknown.

[Trace checks](checks.json) retain intermediate argument-validation flags separately. Such flags do not remove terminal attempts from this comparison.

For a paper with s verified successes in n repetitions, pass^k is C(s,k)/C(n,k), averaged over the 20 papers. It estimates success on every one of k independent attempts; independence is an assumption. Few repetitions cannot establish stable reliability or capture future provider changes.

The JSON includes paired 95% bootstrap intervals over 20 papers, keeping each paper's repetitions together (2,000 resamples; fixed seed). Review-score differences describe rating disagreement, without a ground-truth quality score. Models remain separate. Different methods can have different frozen source archives and start times; the recorded scheduling blocks do not control provider drift or shared-load latency.
